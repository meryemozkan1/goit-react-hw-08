# Phonebook Application (React HW-08)

Bu proje, React, Redux Toolkit ve React Router kullanılarak geliştirilmiş bir iletişim rehberi uygulamasıdır. Kullanıcılar kendi hesaplarını oluşturabilir, giriş yapabilir ve kişisel rehberlerini yönetebilirler.

## 🚀 Proje Hakkında
- **Teknoloji:** React, Vite, Redux Toolkit, React Router.
- **Backend:** [Connections API](https://connections-api.goit.global/)
- **Özellikler:** - JWT tabanlı kimlik doğrulama (Register, Login, Logout).
  - Kullanıcıya özel iletişim listesi.
  - Redux Persist ile token koruması.
  - Private ve Restricted route yönlendirmeleri.
